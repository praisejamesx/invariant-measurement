# Results index

Every number in `paper/draft.md` and `docs/explainer.md` comes from a file in
this directory. The files are generated by the scripts in `experiments/`; the
CSV/JSON files are the source, and `summary.md` is a generated digest.

| paper section | result files | generator |
|---|---|---|
| MOX transfer | `mox/e1_transfer.csv`, `mox/e1_transfer.json` | `experiments/mox/run.py` |
| MOX group stress | `mox/e2_group_stress.csv`, `mox/e2_group_stress.json` | `experiments/mox/run.py` |
| MOX slope stability | `mox/e3_slope_stability.csv`, `mox/e3_slope_stability.json`, `mox/slope_profiles.npz` | `experiments/mox/run.py` |
| NIR representation agreement | `nir_corn/n1_consistency.csv` | `experiments/nir_corn/run.py` |
| NIR group-model fit | `nir_corn/n1_group_fit.csv` | `experiments/nir_corn/run.py` |
| NIR within-instrument CV | `nir_corn/n1_within_cv.csv` | `experiments/nir_corn/run.py` |
| NIR transfer | `nir_corn/n2_transfer.csv`, `nir_corn/n2_transfer_moisture.csv` | `experiments/nir_corn/run.py` |
| NIR reference scaling | `nir_corn/n3_reference_scaling.csv` | `experiments/nir_corn/run.py` |
| NIR anchor sensitivity | `nir_corn/n4_anchor_sensitivity.csv` | `experiments/nir_corn/run.py` |
| EEG | `eeg/eeg_transfer.csv`, `eeg/summary.json` | `experiments/eeg/run.py` |
| Raman | `raman/raman_transfer.csv`, `raman/raman_synthetic.csv`, `raman/summary.json` | `experiments/raman/run.py` |
| Microscopy | `microscopy/microscopy_dice.csv`, `microscopy/summary.json` | `experiments/microscopy/run.py` |
| Mass spec | `massspec/massspec_transfer.csv`, `massspec/summary.json` | `experiments/massspec/run.py` |
| Sequencing | `sequencing/sequencing_transfer.csv`, `sequencing/summary.json` | `experiments/sequencing/run.py` |
| Symbolic proofs | `math_report.txt` | `invmath/groups.py` |
| Aggregate digest | `summary.md` | `experiments/aggregate.py` |
| Dataset fitness | `fitness.csv`, `fitness.md` | `experiments/fitness.py` |

## Regeneration

```bash
python experiments/mox/run.py
python experiments/nir_corn/run.py
python experiments/eeg/run.py
python experiments/raman/run.py
python experiments/microscopy/run.py
python experiments/massspec/run.py
python experiments/sequencing/run.py
python experiments/make_concept_figures.py
python experiments/aggregate.py
python experiments/fitness.py
python experiments/make_references.py
```

`experiments/download_data.py` must be run once before MOX/NIR to populate
`data/` and `data/manifest.json`; the other scripts download their own data on
first run.
